# 表情包工坊

把**一张照片**里的主角，在**自己电脑上**做成一套能上传微信的**动态表情包**。

八张 240×240 的透明底 GIF，加上平台要求的封面、聊天面板图标、详情页横幅，
外加一张对照图让你先看效果、一份提交清单让你照着核对。

主角是谁都行：猫、狗、别的动物，小朋友，或者一个毛绒玩偶。

全程本地跑，照片不出这台机器。

---

## 它能产出什么

一次跑完，工程目录里会多出这些东西：

```
我的表情包/
├── 01_表情图/          ← 8 个动态表情（240×240 GIF，透明底，永久循环）
│   └── _帧图/             每个表情的两帧静态图，想自己再改就改这里
├── 02_封面/            ← 封面_240.png（透明底）
├── 03_聊天面板图标/     ← 图标_50.png（透明底，取的是头部）
├── 04_详情页横幅/       ← 横幅_750x400.png / .jpg
├── 05_对照图/          ← 浅色底 / 深色底的整批对照，用来查透明边
├── 原图/                  模型直接出的图，重做后处理时不用重新出图
├── 提交清单.md          ← 每件素材的实测值 + 平台四条硬要求逐条核对
└── 我家的猫表情包.zip    ← 直接拿去上传的一整套（名字跟着主角走）
```

## 支持哪些主角

界面第 1 步有个「**照片里的主角**」。填什么都能做，工具按它落进三类写法：

| 类别 | 例子 | 「还得是同一个」保的是什么 |
|---|---|---|
| 动物 | 猫、狗、兔子、仓鼠、鹦鹉 | 毛色分布、花纹位置、眼睛颜色 |
| 人物 | 小朋友、我女儿、爷爷 | 发型、脸型、五官、肤色、穿着 |
| 玩偶物件 | 毛绒玩偶、抱枕、书包 | 颜色、材质、图案、配件 |

不填就按猫做。类别只决定提示词怎么写，长相是**你那照片 + 你那句描述**决定的，
所以同一套八组动作谁都能直接用。

想先试试也行：把「用照片当参考」的勾去掉，它只按文字凭空画一个。
实测这条路出的姿势更规整（正面站立、对称），但就不是你家那个了。

## 上传之前：肖像与著作权

表情包是要**公开上架**的，所以照片得是你有权用的：

- 自己拍的，或者已经拿到照片主人同意的
- 不要用名人的照片，也不要用别人的照片
- 不要用别人画的卡通 IP 角色，那是著作权那条线
- 工具本身不联网。照片只在这台电脑上被 ComfyUI 读一次，不会传到任何地方

这条跟「像不像」无关，是**能不能发**的问题。八张图几分钟就出来了，
真被下架或者被人找上门，不值当。

## 需要什么

| 项 | 说明 |
|---|---|
| ComfyUI | 要能跑起来，并且支持 `TextEncodeQwenImage21` 节点（较新版本自带） |
| 模型 | Qwen-Image-2.1（扩散模型 + 文本编码器 + VAE） |
| Python | 只用标准库 + Pillow + numpy。**ComfyUI 便携版自带的 `python_embeded` 里两个都有**，所以通常什么都不用装 |
| 显存 | 16GB 能跑（本机 RTX 4080 实测）。8GB 可能需要更小的量化 |

## 怎么用

1. **启动 ComfyUI**（它要一直开着，这个工具靠它出图）
2. **双击 `start.bat`**（macOS / Linux 是 `./start.sh`）
3. 浏览器会自动打开界面，然后：

```
传一张照片 + 填一句它是什么  →  说说它长什么样  →  挑八个词  →  点「一键生成整套表情」
```

四步做完，右边进度条走完，底下就能看到八张 GIF。满意就下载 zip。

### 想先确认一下？

界面上有个「**先出定妆照让我看一眼**」的勾选框。勾上之后，它会只出一张定妆照就停下来，
你看一眼：像不像你家那个？像就点「就它了，继续出表情」，不像就换个种子重出。

**这一步值得花那二十秒。** 定妆照是整套一致性的唯一来源 —— 它不像，后面十六张都会跟着不像，
而重出十六张要几分钟。

### 某一张不满意？

每张 GIF 下面都有「这一张重出」，单独重跑那一张就行，不用整套重来。

## 几个可能想问的问题

**为什么字是让模型画，而不是事后用字体贴上去？**
因为贴合度。模型画的字会跟着画面透视、描边、光照走，字体贴上去永远是浮在上面的一层。
实测单行 2~4 个汉字模型全写对，笔画都对，所以这条路走得通。
超过 4 个字就开始缺笔画、写错字 —— 界面上那八个词建议就控制在这个长度。

**为什么背景要纯绿色？**
表情包要透明底，但让模型直接给「透明」不可靠。给一块纯色反而抠得干净：
从画面四角做连通域填充，只抠「跟边缘连着的绿」，角色身上就算有绿色也不会被抠掉。
抠完还要去一遍绿边，否则贴到微信深色聊天底上会有一圈荧光绿。

**为什么照片的姿势会被带进来？**
因为参考图的权重就是很高。实测：给一张坐着的猫，出来的定妆照也是坐着的，
就算提示词里写了「正面站立」也压不过它。
所以，**想要一个正面站好的底子，就传一张正面站好的照片**。这一条比改提示词有用得多。

**能不能不用照片，只按文字描述画一个？**
可以。把「用照片当参考」那个勾去掉，它会照着你写的那句话凭空画。
实测这样出来的姿势更规范（正面站立、对称），但当然就不是你家那个了。

**一张照片都没有怎么办？**
那就先拍一张。正面、全身入镜、光线均匀、别有太多杂物 —— 这四条满足三条就够用了。
人像也一样，正面站直、光线均匀的一张最好用。

**换主角会不会把之前的表情弄乱？**
不会。主角、描述、八个词、种子都记在工程目录的 `生成记录.json` 里，
换工程目录就是另开一局。真重跑的时候，`原图/` 里已经出的帧会被复用，
只出缺的那几张。

**审核要多久？**
平台口径是 5 个工作日。上架之后**每自然月只能改 1 次**，改完重新排队，
所以提交前把尺寸、透明底、文案对着 `提交清单.md` 自查一遍。

## 命令行

```bash
python app.py --check           # 只体检：ComfyUI 通不通、模型在不在、Pillow 有没有
python app.py --work 小狗表情包   # 换个工程目录
python app.py --port 9000       # 换个端口
```

`--check` 出问题时它会告诉你差什么，以及该改 `config.json` 的哪一行。

## 配置

都写在 `config.json` 里，界面上「设置」改的是同一个文件，不会分叉。

```json
{
  "comfy_url": "http://127.0.0.1:8188",
  "models": { "unet": "...", "clip": "...", "vae": "..." },
  "generate": { "steps": 25, "cfg": 1, "sampler": "euler", "scheduler": "simple" },
  "sticker":  { "size": 240, "frame_ms": 400, "edge_trim": 0.055, "alpha_cut": 128 },
  "assets":   { "banner_trim_y": 0.06, "icon_head_band": 0.45 }
}
```

- `frame_ms` 是每帧停留毫秒数，400 大约是一秒两个来回
- `edge_trim` 是八张共用的裁切窗口（四周各去掉 5.5%）—— **不要改成"每张各自裁紧"**，
  那样八张的大小会参差
- `alpha_cut` 是 GIF 透明度的硬阈值。GIF 只有「透明」和「不透明」两种，没有半透明
- `icon_head_band` 是图标取头部时量的那段比例。0.45 是按 Q 版造型定的
  （头本身就占近一半身高）。**换成人像或玩偶如果图标取景不理想，调这一个数**

## 平台规格（提交前核对）

| 素材 | 尺寸 | 格式 | 体积 | 透明底 |
|---|---|---|---|---|
| 表情图 8~24 张 | 240×240 | GIF / PNG | ≤500KB | 建议透明 |
| 表情封面图 | 240×240 | PNG | ≤500KB | **必须** |
| 聊天面板图标 | 50×50 | PNG | ≤100KB | **必须** |
| 详情页横幅 | 750×400 | PNG / JPG | ≤500KB | 不要求 |

另外四条：同一套必须**统一是动态或统一是静态**（本工具统一出动态）；
各张**风格要统一**（靠同一张定妆照）；各张**要有足够差异**；
动态表情**必须循环播放**（本工具默认永久循环）。
还有一条容易被忽略：**仅仅为了满足"动态"而做无意义的缩放、平移、晃动、闪烁，不能过审** ——
所以这里每一张的两帧是**内容真的变了**，不是位移。

横幅单独有三条：**避免任何文字、避免白底、避免透明底**。本工具默认用淡蓝色底。

## 目录结构

```
app.py                 启动入口
config.json            配置
start.bat / start.sh   启动脚本（优先用 ComfyUI 自带的 python_embeded）
studio/
  comfy.py             ComfyUI 客户端（零依赖，自带绕代理）
  workflows.py         拼 ComfyUI 的 API 工作流
  prompts.py           提示词模板（主角三类写法 / 角色锚 / 风格段 / 八个表情）
  cutout.py            色键抠图 + 去绿边
  sticker.py           → 240² 动态表情（含两帧差异度量）
  assets.py            封面 / 图标 / 横幅
  pack.py              提交清单 + 打包
  pipeline.py          把上面串成「一键生成」
  web.py               本地界面与接口
web/                   前端（原生 HTML/CSS/JS，无框架）
```
